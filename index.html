Copy Paster

Save a terminal command once, then copy it on any computer.

Shared across computers

Commands are stored in this GitHub repo. Another computer sees them when you open or refresh this page. Paste a token here to save.

Saved commands are public in Patios/Copy-paster. Don't store secrets.

Create a token
  1. Create a fine-grained token for the repository Patios/Copy-paster.
  2. Set Contents to Read and write.
  3. Paste it above on each computer you want to save from. Viewing needs no token.

Save a command

Publishes the command to GitHub. Refresh this page on another computer to see it.
