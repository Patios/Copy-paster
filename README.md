# Copy Paster

Save terminal commands and copy them on any computer.

Live page: https://patios.github.io/Copy-paster/

Commands are stored in [`commands.json`](commands.json) in this public repository. Opening the page on another computer shows the same list after a refresh.

To save from a browser, create a [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) for **Patios/Copy-paster** with **Contents: Read and write**, then paste it into the page. The token stays in that browser. Viewing and copying do not need a token.

Saved commands are public. Don't store secrets in them.
